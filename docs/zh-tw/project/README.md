# 專案快照和 Triage 文件

時間限制的專案狀態快照，用於計劃和運維文件。

## 目前快照

- [../../maintainers/project-triage-snapshot-2026-02-18.md](../../maintainers/project-triage-snapshot-2026-02-18.md)

## 範圍

專案快照是對開放 PR、issue 和文件狀態的時間限制評估。使用它們來：

- 識別由功能工作推動的文件缺口
- 優先考慮與程式碼變更並行的文件維護
- 隨時間追蹤 PR/issue 壓力

如需穩定的（非時間限制的）文件 triage，請使用 [../../maintainers/docs-inventory.md](../../maintainers/docs-inventory.md)。
